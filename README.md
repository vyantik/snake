# Snake Game

Классическая игра "Змейка", написанная на Go с использованием библиотеки raylib-go.

## Описание

Это простая реализация классической игры "Змейка", где игрок управляет змейкой, собирая еду и избегая столкновений со стенами и собственным телом. Проект написан на языке программирования Go с использованием библиотеки raylib-go для графического интерфейса.

## Требования

-   Go 1.24.2 или выше
-   Зависимости, указанные в go.mod

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/vyantik/snake.git
cd snake
```

2. Установите зависимости:

```bash
go mod download
```

## Запуск

```bash
go run main.go
```

## Управление

-   Стрелки вверх/вниз/влево/вправо - управление направлением движения змейки
-   ESC - выход из игры

## Структура проекта

-   `main.go` - точка входа в приложение
-   `game/` - логика игры
-   `snake/` - реализация змейки
-   `food/` - логика генерации еды
-   `constants/` - константы игры
-   `colors/` - цветовые константы
-   `assets/` - ресурсы игры
-   `deque/` - реализация двусторонней очереди
